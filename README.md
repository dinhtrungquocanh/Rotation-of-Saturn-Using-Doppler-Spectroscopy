This is the project for Group S3 at the 48th International School for Young Astronomers.
The Notebooks were run on Google Colab. Here is the Google Drive Link for the Data: https://drive.google.com/drive/folders/1TRIvXDKh0F0ilQb-Xv-K01bL30EvR_lA?usp=sharing

In the Google Drive:
- The raw data are stored in folder 'Hi-Res Spec Data'
- The reduced data are stored in the sub folder 'Reduced-Python-new'

About the notebooks:
- The 'S3_data_reduction.ipynb' is for data reduction. 
- The 'S3_tracing_and_calculation.ipynb' is for spectrum tracing and Doppler calculation

Further references for our codes:
